# Portrait Current

Adapted from **Interactive Particles** by Bruno Imbrizi / Codrops, fixed
revision `efe300f9cd2b976da377ed43e9f50662fb575bf7`.

- Source: https://github.com/brunoimbrizi/interactive-particles

- Article: https://tympanus.net/codrops/2019/01/17/interactive-particles-with-three-js/
- License terms: `public/THIRD_PARTY_NOTICES.txt`

The original Three.js 0.98 particle shaders, instanced quad geometry, CPU dark
pixel discard, image sampling, 64×64 touch texture, trail aging, raycast UV
mapping, and default parameters are retained. The product layer replaces the
sample image with the current player's avatar, adds a 12-cell spatial discovery
loop, portable Vite packaging, lifecycle/performance guards, QA and publishing
metadata. It is not an as-is redistribution.

Use `?baseline=1` for the restored samples; tap cycles through all five.
