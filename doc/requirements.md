# Requirements

## 1. Overview

Portrait Current 是一个 45–90 秒的头像粒子触屏玩具：当前玩家头像被拆成 WebGL 粒子或同尺度的 180×180 随机圆粒蒙版，手指划过会唤醒局部电流；探索足够多的画面区域后，画面收束成清晰肖像。

## 2. Visual Design

保留 Interactive Particles 的黑色舞台、320×180 原样基线、实例化圆片、灰度取样、随机深度、simplex 噪声、64×64 离屏触摸纹理和局部推力。产品态把主体替换为正方形 center-cover 的玩家头像；可读图片保持原 WebGL 粒子，无 CORS 的平台头像通过单张连续照片和 4× 精度生成的 180×180 随机圆粒蒙版成像，并统一转为高曝光黑白，避免彩色照片偏离原作或换成缺省图。界面只增加安全区标题、12 格覆盖进度、底部指引和 44px 重置。

## 3. Game Mechanics

像素可读时，红通道不高于 34 的像素在 CPU 端剔除，其余像素各生成一个 instanced quad；默认 `uRandom=2`、`uDepth=4`、`uSize=1.5`。平台头像不可读像素时，在 720×720 内存画布上为 180×180 个采样格生成互不粘连、半径 0.25–0.49 格的随机圆粒蒙版；真实照片只显示一次，以 `grayscale(1) contrast(1.3) brightness(1.55)` 保留五官中间调并提高白点曝光。画面统一划分为 4×3 共 12 个探索格；达到 9 格时完成。WebGL 触摸纹理尺寸 64、最大年龄 120 帧、半径 0.15。

## 4. Controls

单指在头像上按住并拖动；WebGL 路径由 raycaster 映射 UV，平台蒙版路径由头像矩形映射 UV。每个新网格同帧更新进度；重复划同一格仍产生电流反馈但不重复计数。完成后仍可触摸画面；重置清空覆盖。

## 5. Win / Lose Conditions

触达 12 格中的任意 9 格即完成肖像收束，显示完成文案和重置。无倒计时、分数、生命或失败。

## 6. Sound Effects

无音频。离屏触摸波、网格进度和粒子收束提供即时视觉反馈。
